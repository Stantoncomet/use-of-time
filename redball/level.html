Red Ball, a game by OM

Tick Rate: 50ms

Controls

  • Use WASD to select direction blocks.
  • Use Space to run ball. Current board is saved until space is pressed again.
  • Use Space again to reset ball and any changes made while ball was running.
  • Use E to select eraser.
  • Set window zoom level to 120% (ctrl + +).
  • Load levels using the text box below and the load button.

Game

    The ball moves at a constant speed. When it moves over a block,
    it will adopt the direction of the block, and the block will
    flip to the opposite direction.

    Complete levels by moving ball to the goal.
